## Priority / invariants

1. **Stobj logical/raw agreement** (notes 6.0, 6.1, 6.2, 6.3, 6.4, 6.5): every update must be returned, recognizers must remain true, abstract updates must be atomic or protected, congruent/nested accesses must not alias, and child updates must invalidate parent memoization.
2. **Safe evaluation agrees with logic** (notes 4.0 non-executable, 4.1 MV-in-guard, 4.3 `mbe`, 5.0 hidden host state): definition/macro/constant/make-event evaluation must not run a different value from the logical term.
3. **Rule validity** (4.0/4.2 elim and forcing, 6.4 congruence/expand, 6.5 tau): generated clauses and installed rules must be logical consequences, including under forcing and newer term shapes.
4. **Certificate/world identity** (4.0 portcullis, 4.2 packages, 6.1 expansion files): including a book must reconstruct the exact logical world certified.

No confirmed new soundness bug. No executed script proved a false theorem or returned two values for one closed term.
