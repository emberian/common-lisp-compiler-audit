# ACL2 historical soundness siblings

Source audited: `/Users/ember/dev/acl2-fix/head-worktree` (commit specified by the brief: `1d2b39a424`, ACL2 8.7+ development snapshot). All execution is via `../lisp-run.sh` from fresh ACL2 images. Scripts in this directory are probes unless explicitly called reproducers. No claimed soundness finding below uses `skip-proofs`, `defaxiom`, trust tags, `:redef`, or raw-Lisp redefinition.

## Priority / invariant map

1. **Meta/clause-processor output must be legal, logic-mode, and free of forbidden symbols** (7.1, 7.3, 8.3). New routes: `apply$`, `loop$`, warrants, `defun-nx`/`non-exec`, attachments. Source checks: `logic-termp`, `logic-fnsp`, `meta-extract-formula`, `mfc-rw`.
2. **Functional substitution must respect universal quantification and primitive constraints** (7.4, 8.1). New routes: quoted lambdas, `lambda$`, `loop$`, `return-last`/`mv-list`, warrants. Source checks: `remove-capture-in-constraint-lst`, `*non-instantiable-primitives*`, `instantiablep`.
3. **Logical stobj types/recognizers and raw stobj representation must agree, including under aliasing and attachment** (7.2, 8.0, 8.5, 8.6, 8.7). New routes: congruent/nested/abstract stobjs, stobj tables, `with-global-stobj`, `defattach`. Source checks: invariant-risk, `stobj-attachment-restrictions`, live-stobj checks, `stobj-let` producer restrictions.
4. **Memoized/defattach dependency graphs must be conservative** (7.0, 8.2). New routes: `memoize-partial`, macro aliases, warrants, stobj-table fields. Source: `immediate-canonical-ancestors` and attachment checks.
5. **Logic/exec definitions must not be conflated** (8.4 `defabsstobj`/`mbe`; 7.0 `never-memoize-fn`). New routes: `defun-nx`, `non-exec`, `return-last`, `ec-call`, compiled quoted lambdas.
6. **State-independent logical functions must really be state-independent** (7.1 include-book dirs, 7.2 guard checking, 8.4 string printing, 8.6 file reads). New routes: expansion files, global stobjs, raw mode.

## Confirmed

### Admission divergence (not a soundness claim)

- **CCL rejects, while SBCL admits, a constrained predicate in a nullable stobj field whose initial value is NIL.** Reproducer: `repro-defstobj-ccl-init.lisp` (the initial probe was `probe-defstobj-constrained-init.lisp`); run with `../lisp-run.sh acl2-sbcl repro-defstobj-ccl-init.lisp` and `../lisp-run.sh acl2-ccl repro-defstobj-ccl-init.lisp`. The two definitions are just `(defstub p (x) nil)` and `(defstobj st (fld :type (or null (satisfies p)) :initially nil))`. SBCL prints `DEFSTOBJ completed; STP on logical initial object: T`. CCL instead reports `ACL2 Error [Evaluation] in TOP-LEVEL: ACL2 cannot ev the call of non-executable function P on argument list: (NIL)` and rolls back `ST`. This is an **ERROR where admission was expected**, not a wrong value or false theorem. The same event shape is used by the 8.7 attachment regression, so on CCL it can prevent the later attachment check from being reached (`probe-stobj-attach-concrete.lisp.acl2-ccl.out`). No guard-violating user raw code is involved.

No wrong value or proof of a false theorem has been confirmed.

## Refuted

1. **7.4 free variable in a functional-substitution lambda (original exploit).** `probe-capture-7-4.lisp`, SBCL ACL2: `not-true` fails; `remove-capture-in-constraint-lst` emits `Capture` with `((N . N-RENAMED0))`, leaving the unprovable constraint `(EQUAL N-RENAMED0 3)`. The downstream `ouch` also fails because `not-true` was not admitted. No false theorem.
2. **The later fresh-name collision sibling of the same capture invariant.** `probe-capture-freshname.lisp`, SBCL ACL2: `nil-proved` fails. The check chooses `A-RENAMED1` (avoiding the existing formal `A-RENAMED0`) and leaves `(IMPLIES (NOT (EQUAL A-RENAMED1 A-RENAMED0)) (EQUAL A 3))`. This directly exercises the extended avoid-set in `history-management.lisp:12173-12346`.
3. **8.1 implicit functional instantiation of `O<`'s termination theorem (original exploit).** `probe-termination-o-less.lisp`, SBCL ACL2: admission of `bad` fails on its measure conjecture; all dependent events fail. `O<` is in `*non-instantiable-primitives*` (`history-management.lisp:10791-10876`), so the former self-justifying instantiation is unavailable. The transcript is large because the failed measure proof proceeds by induction.
4. **8.1 tau conversion of non-strict inequalities on non-numbers.** `probe-tau-nonnumber.lisp`, SBCL ACL2: both `(or (< x 0) (= x 0) (> x 0))` and `(implies (and (not (equal x 0)) (<= x 0)) (< x 0))` fail. Both leave the forced numeric obligation `(IMPLIES (NOT (RATIONALP X)) (ACL2-NUMBERP X))`; adding `acl2-numberp` makes the trichotomy control prove. An extra raw evaluation control using `(< t 0)` was guard-violating and is not evidence.
5. **8.4 `loop$` with bare `:guard` as body/test.** `probe-loop-guard.lisp`, SBCL and CCL ACL2: `collect :guard`, `when :guard`, and `until :guard` are all rejected by `translate` as illegal `LOOP$` syntax; the documented quoted-keyword control `collect ':guard` proves. This matches `translate.lisp:18881-18952`. An attempted `for ... do :guard` form was also rejected, but it used invalid `DO` placement and is not evidence about `DO LOOP$`.
6. **8.5 `(satisfies evenp)` stobj field and its false guard-theorem exploit.** `probe-stobj-satisfies.lisp`, SBCL ACL2: `defstobj` rejects the field because `(EVENP X)` cannot be checked guard-verified; consequently `(:guard-theorem fieldp)` is ill-formed and `bad` fails.
7. **The same stobj predicate-guard invariant through `defun-nx`.** Same script: `nx-evenp` has a nontrivial `integerp` guard. With a nullable field (so initial-value evaluation does not mask the check), `defstobj` rejects `(OR (EQ X NIL) (NX-EVENP X))` as not checkably guard-verified. An earlier non-nullable variant was rejected earlier because the non-executable predicate could not evaluate on `4`; only the final transcript is used for this refutation.
8. **8.4 state-dependent `fmt1-to-string` under a local evisc table.** `probe-fmt-state.lisp`, SBCL ACL2: the original encapsulate proves `it-is-7`, while the former outside theorem `(equal *c* 13)` now fails by simplification to NIL. Thus the local evisc setting does not leak into the exported constant.
9. **The same printing invariant through `make-event`.** Same script: a `make-event` inside the local-evisc encapsulate produces the same `defconst`; `me-is-7` proves and `me-is-13` fails. No expansion-pass state dependence was observed.
10. **8.7 concrete stobj recognizer/attachment dependency, both event orders.** `probe-stobj-attach-concrete.lisp`, SBCL ACL2: attaching first makes `defstobj` fail because its recognizer would depend on the attachment; creating first makes `defattach` fail because the predicate is an ancestor of the recognizer. Both errors name `stobj-attachment-restrictions`. On CCL the first order is rejected identically, but the second order is masked by the separate initialization error in Confirmed above.
11. **8.3 `meta-extract-formula` and `fncall-term` on a program-mode function.** `probe-meta-extract-program.lisp`, SBCL ACL2: both assertions pass, returning the trivial term `'T` for `prog-nil`. A `defun-nx` logic-mode control legitimately has a nontrivial logical formula (containing `RETURN-LAST`/`THROW-NONEXEC-ERROR`); `fncall-term` still returns `'T` because the function is non-executable.
12. **7.1 forbidden calls and 7.3 program-mode calls emitted by a proved clause processor.** `probe-clause-dead-branch.lisp`, SBCL and CCL ACL2: `cp-forbidden-correct` and `cp-program-correct` prove. Each puts its target call in `(IF 'T NIL ...)`, so the correctness result does not depend on evaluating that call. Applying each to the false goal NIL is rejected because the output contains a non-`termp`; no false theorem is admitted.
13. **The same prover-output invariant through `apply$` and a quoted lambda.** Same script, SBCL and CCL ACL2: `cp-apply-lambda-correct` proves, with `(PPROG X)` nested in `(APPLY$ '(LAMBDA (X) (PPROG X)) '(NIL))` in the dead branch. The false-goal application is rejected as non-`termp`; quoted-lambda nesting does not bypass the output check.
14. **8.0 congruent-stobj `stobj-let` aliasing (original proof of NIL).** `probe-stobj-let-alias.lisp`, SBCL ACL2: the historical `true-and-false-is-true` still proves, but `true-and-false-is-contradictory-2` fails, simplifying to NIL. The source test notes that the runtime robust aliasing check prevents the former raw/logical disagreement.
15. **Memoization through a congruent stobj hash-table update.** `probe-memoize-congruent-ht.lisp`, SBCL and CCL ACL2: honest `true-prop` proves before memoization; after `(memoize 'rd)`, former false-prop `(test)` fails. The congruent representative's memoization entries are flushed, so stale `3` does not survive `ht2-rem`.
16. **World-dependent `memoize :invoke` via a macro alias and encapsulate pass 2.** `probe-memoize-macro-alias.lisp`, SBCL ACL2: pass 1 selects `GOOD`, but pass 2 rejects the table update because nonlocal `(DEFTHM VICTIM-IS-G (EQUAL (VICTIM X) (G X)))` has not been admitted. The encapsulate fails with a local incompatibility; no redefinition of `victim` survives.
17. **7.2 array invariant-risk through direct code, `FOR LOOP$`, and `DO LOOP$`.** `probe-array-invariant-loops.lisp`, SBCL and CCL ACL2: all three program-mode `aset1` routes produce an `Invariant-risk` warning and an `ASET1` guard error for index 10. 18. **The same array invariant through `mbe`, `ec-call`, and explicit `return-last`.** `probe-array-invariant-wrappers.lisp`, SBCL and CCL ACL2: all three calls fail with the `ASET1` bounds guard, and all following adjacent-array assertions pass. `mbe` and `return-last` also produce invariant-risk warnings; `ec-call` reaches the guard check directly.
19. **8.4 counterfeit `record-expansion` across certified books (original exploit).** Sources are in `probe-record-expansion/`; drivers `probe-record-expansion-driver.lisp`, `-2.lisp`, and `-top.lisp` (the latter two are separate fresh-image runs).
